# Automation Testing Framework Portfolio

This repository contains a comprehensive suite of automated tests and framework implementations, developed as part of an advanced Python Automation and Testing program. It showcases practical applications of web UI automation, API testing, and Behavior-Driven Development (BDD).

## Technical Stack
* **Programming Language:** Python 3.x
* **Web UI Automation:** Selenium WebDriver
* **Testing Frameworks:** PyTest, Unittest, Robot Framework
* **API & BDD:** Python Requests, Behave (Gherkin)
* **Design Patterns:** Page Object Model (POM), Data-Driven Testing

## Repository Structure

### 1. Initial Lab Work and Video Demonstrations
Contains module-wise laboratory workbooks detailing experimental problem statements, objectives, and clean source code implementations. Topics cover:
* DOM locators, explicit/implicit synchronization, and dynamic web tables.
* Advanced `ActionChains` (Drag and Drop, Keyboard simulations, Mouse Hovers).
* JavaScript alerts, iframe handling, and multi-window context switching.
* Includes demonstration videos of framework execution.

### 2. Capstone Project
Features a complete, scalable automation framework utilizing **Python Requests and Behave BDD**. 
* **Objective:** Automate the User Management API of a REST service.
* **Architecture:** Incorporates reusable framework design, custom utilities, configuration management, and comprehensive reporting.

### 3. Certificates
Contains verified credentials and course completion certificates from the prescribed curriculum.
